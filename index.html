Occupation selector — four search behaviours

Zack Taylor, University of Western Ontario · source on GitHub

These are four working versions of a bilingual occupation-search widget for Qualtrics surveys, built on the National Occupational Classification (NOC) 2021. A respondent types what they do for a living and picks from a dropdown; the widget records the 5-digit NOC code behind their choice.

All four wrap the same classification and resolve to the same codes. What differs is what the respondent sees, what the search actually matches against, and the order results appear in. The point of this page is to make those differences easy to feel rather than describe, so we can decide which to field.

Things worth trying

Type nurse into all four and compare: categories returns 5 results, tomselect 15, keywords 153, longlist 158.
Type head nurse: only the versions that search titles will find anything.
Type manager to see the cost of alphabetical ordering — roughly 1,200 titles match, so the list opens at Abattoir manager and never reaches the useful ones.
Switch to Français after choosing something, and watch what survives the switch.
Every selection updates the embedded-data panel underneath, exactly as it would be written into a Qualtrics response.

This is a demonstration harness, not a live survey — nothing you type here is recorded or transmitted anywhere. The widgets are the unmodified production scripts, running against a small stand-in for the Qualtrics survey engine. Full documentation for each version is in the repository.
